# カタグルマ CS お助けアシスタント

CSメンバーが顧客対応で躓いたときに、**FAQ・ナイスアシスト事例・テンプレ運用ノウハウ**をもとに最適な打ち手をAIが提案する社内Webアプリです。

- 想定する相談：①システムのドメイン知識・仕様の質問 ②「こういう使い方できる？」の応用相談 ③忙しくて活用が停滞しているユーザーへのアプローチ相談
- 構成：単一HTML（`index.html`）＋知識ベース（`kb.js`）。Claude APIを各CSメンバーのキーでブラウザから直接呼び出します。サーバ不要。
- 配布：GitHub Pages（公開URL）。顧客法人名・個人名は**匿名化済み**。

---

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（UI＋Claude API呼び出し） |
| `kb.js` | 知識ベース（匿名化済みのFAQ・事例・タイプ別アプローチ・テンプレ） |
| `README.md` | このガイド |
| `_serve.ps1` | ローカル動作確認用の簡易サーバ（配布不要・GitHubに上げなくてOK） |

---

## セットアップ（GitHub Pages で配布）

1. GitHubでリポジトリを新規作成（例：`katagrma-cs-assistant`）。
2. `index.html` と `kb.js` をアップロード（`_serve.ps1` は不要）。
3. リポジトリの **Settings → Pages** → Source を `Deploy from a branch` → `main` / `/(root)` に設定して保存。
4. 数分後に `https://<アカウント>.github.io/katagrma-cs-assistant/` が発行されます。これをCSメンバーに共有。

> ⚠️ GitHub Pagesを無料プランで使う場合はリポジトリを**公開（Public）**にする必要があります。URLを知っていれば誰でも中身を見られる状態になるため、`kb.js` に法人名・個人名や機微な内容を書かないよう徹底してください（匿名化・中立表現の徹底）。URL自体も社内限定で共有してください。

## 各メンバーの初回設定
1. 共有されたURLを開く。
2. 右上「⚙ 設定」→ **自分のClaude APIキー**（`sk-ant-...`）を登録。[コンソールで発行](https://console.anthropic.com/settings/keys)。
   - キーは**そのブラウザのlocalStorageにのみ保存**され、Anthropic以外に送信されません。
3. 困りごと／質問を入力して「提案してもらう」。プラン・オンボ状況を指定するとより的確になります。

## 使い方のコツ
- 停滞ユーザーの相談は、状況（園長多忙・運用バラバラ・以前断られた等）を書くほど、該当タイプの打ち手＋声かけ例が出ます。
- 仕様の質問は、AIが不確かな場合「担当・資料で確認を」と添えます。**最終判断はCS担当者が**。

## モデルと費用
- 既定は **Sonnet 5**（速い・安い）。品質重視なら **Opus 5**、最速・最安なら **Haiku 4.5** を画面右のプルダウンで選択。
- 従量課金は各自のキー。知識ベース全体はプロンプトキャッシュ対象なので、連続利用時のコストは抑えられます。
- 既定モデルを変えたい場合は `index.html` のモデル選択 `<select id="model">` の `selected` を付け替え。

---

## 知識ベース（kb.js）の更新
新しいFAQや事例が溜まったら `kb.js` を編集して再アップロードするだけで反映されます。**顧客法人名・個人名は必ず役割表現（園長／主任／理事長／本部担当 等）に置換**してください。

```js
// 事例を追加する例（cases 配列に追記）
{ theme:"見出し", service:"人財育成", situation:"状況", approach:"打ち手", result:"結果" },

// FAQを追加する例（faq 配列に追記）
{ fn:"個人面談", q:"質問", state:"OB①", a:"回答" },
```
`updated` の日付も更新すると、画面フッターに反映されます。

## ローカルで試す（任意）
PowerShellで `./_serve.ps1` を実行 → ブラウザで `http://localhost:8791/` を開く。

## 注意事項
- 本ツールはAI生成の提案です。仕様・運用の最終確認と顧客対応の判断はCS担当者が行ってください。
- `kb.js` は匿名化済みですが、率直な社内評価コメント等の追記は避け、載せる場合も中立表現にしてください（公開URLのため）。
